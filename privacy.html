プライバシーポリシー

最終更新日：2026年9月9日

NORI（以下「本アプリ」）は、日本国内のパーティー・音楽イベント・交流会を発見し、参加登録、チケット購入、QR入場などを行うためのアプリです。本ポリシーは、本アプリの運営者（以下「当方」）が、本アプリの利用にあたって取得する情報とその取り扱いについて定めるものです。

1. 取得する情報

当方は、本アプリの提供のために必要な範囲で、以下の情報を取得します。

種類具体例目的
アカウント情報メールアドレス、氏名・ニックネーム、プロフィール画像アカウント作成・本人確認・表示
認証識別子Google／Apple のアカウント識別子、当方が発行するユーザーIDログイン・認証
イベント・購入情報参加登録したイベント、チケットの購入履歴参加管理・チケット発行・入場
ユーザー投稿コンテンツ写真・動画、イベントに関する投稿プロフィール・イベント表示
端末情報デバイス識別子、プッシュ通知トークン通知配信・不正防止・動作改善

本アプリは、広告目的やクロスサイト・クロスアプリのトラッキングのために情報を利用しません。

2. 利用目的

  • 本アプリの機能（アカウント認証、イベントの発見・参加登録、チケット購入、QR入場、通知）の提供
  • ユーザーサポートおよびお問い合わせへの対応
  • 不正利用の防止、および本アプリの安全性・品質の維持向上
  • 法令上の義務の遵守

3. Googleアカウントでのログインについて

Googleアカウントでログインを行う場合、当方は Google から、あなたの基本的なプロフィール情報（氏名、メールアドレス、プロフィール画像、Googleアカウント識別子）を取得します。取得した情報はアカウントの作成・認証・本アプリ内での表示にのみ利用し、上記の目的の範囲を超えて利用しません。Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー（Limited Use を含む）に準拠します。

4. 第三者への提供・業務委託

当方は、法令に基づく場合を除き、ご本人の同意なく個人情報を第三者に提供しません。ただし、本アプリの提供に必要な範囲で、以下の外部サービスにデータの処理を委託しています。

  • Supabase（認証・データベース・ストレージ基盤）
  • Stripe（チケット決済の処理。カード情報は Stripe が処理し、当方は保持しません）
  • Google／Apple（ソーシャルログインによる認証）
  • Expo（プッシュ通知の配信）
  • Google Maps（地図・位置の表示）

5. データの保管と国際移転

取得した情報は、上記の委託先が管理するサーバーに保管されます。これらのサーバーは日本国外に所在する場合があり、その場合、情報は国境を越えて移転・保管されることがあります。当方および委託先は、適切な安全管理措置を講じます。

6. データの保存期間と削除

取得した情報は、利用目的の達成に必要な期間、または法令で求められる期間保管します。アカウントの削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。合理的な期間内に、法令上保持が必要なものを除き、あなたのアカウントおよび関連情報を削除します。

7. ユーザーの権利

あなたは、当方が保有するご自身の個人情報について、開示・訂正・利用停止・削除を求めることができます。ご希望の場合は下記のお問い合わせ先までご連絡ください。

8. 未成年の方の利用

未成年の方が本アプリを利用する場合は、保護者の同意を得たうえでご利用ください。

9. 本ポリシーの変更

当方は、必要に応じて本ポリシーを変更することがあります。重要な変更を行う場合は、本ページ上でお知らせします。変更後の本ポリシーは、本ページに掲載した時点から効力を生じます。
