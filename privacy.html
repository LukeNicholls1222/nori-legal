2. 利用目的

  • 本サービスの機能（アカウント認証、イベントの発見・参加登録、チケット購入・発券・入場、通知）の提供
  • ユーザーサポートおよびお問い合わせへの対応
  • 不正利用の防止、本サービスの安全性・品質の維持向上
  • 法令上の義務の遵守

3. Google／Apple アカウントでのログイン

ソーシャルログインを利用する場合、当方は Google または Apple から、氏名、メールアドレス、プロフィール画像、アカウント識別子等の基本的なプロフィール情報を取得します。取得した情報はアカウントの作成・認証・本サービス内での表示にのみ利用します。Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー（Limited Use を含む）に準拠します。

4. 主催者への情報提供

参加者がイベントに参加登録・チケット購入を行った場合、当方は、イベント運営に必要な範囲で、参加者の氏名・メールアドレス・参加状況等を当該イベントの主催者に提供します。提供の目的は、イベントの中止・変更の連絡、返金対応、入場時の本人確認等です。主催者が取得した情報の取り扱いは、主催者自身の責任および主催者のプライバシーポリシーによります。

5. 業務委託・第三者提供

当方は、法令に基づく場合を除き、ご本人の同意なく個人情報を第三者に提供しません。ただし、本サービスの提供に必要な範囲で、以下の外部サービスに処理を委託しています。

  • Supabase（認証・データベース・ストレージ基盤）
  • Stripe（決済処理。カード情報は Stripe が直接取り扱います）
  • Google／Apple（ソーシャルログインによる認証）
  • Expo（プッシュ通知の配信）
  • Google Maps（地図・位置の表示）

6. データの保管と国際移転

取得した情報は、上記委託先が管理するサーバーに保管されます。これらのサーバーは日本国外に所在する場合があり、その場合、情報は国境を越えて移転・保管されることがあります。当方および委託先は、適切な安全管理措置を講じます。

7. 保存期間と削除

取得した情報は、利用目的の達成に必要な期間、または法令で求められる期間保管します。アカウントの削除をご希望の場合はアプリ内の退会手続または下記お問い合わせ先までご連絡ください。法令上保持が必要なもの（取引記録等）を除き、合理的な期間内に削除します。

8. 安全管理措置

当方は、取得した情報の漏えい・滅失・毀損の防止その他の安全管理のために、必要かつ適切な措置を講じます。通信は暗号化（HTTPS）により保護されます。

9. ご本人の権利

ご本人は、当方が保有するご自身の個人情報について、開示・訂正・利用停止・削除を求めることができます。ご希望の場合は下記お問い合わせ先までご連絡ください。ご本人であることを確認したうえで、法令に従い対応します。

10. 未成年者について

未成年の方は、親権者等の法定代理人の同意を得たうえでご利用ください。

11. 本ポリシーの変更

当方は、必要に応じて本ポリシーを変更することがあります。重要な変更を行う場合は本ページで周知し、変更後のポリシーは掲載時点から効力を生じます。
