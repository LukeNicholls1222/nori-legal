2. 利用目的

  • 本サービスの機能（アカウント認証、イベントの発見・参加登録、チケット購入・発券・入場、通知）の提供
  • 年齢制限のあるイベントへの参加可否の確認
  • 主催者への売上の支払い、返金・キャンセルの処理
  • ユーザーサポートおよびお問い合わせへの対応
  • 不正利用の防止、通報への対応、本サービスの安全性の維持
  • 利用状況の分析による本サービスの改善（個人を特定した広告には利用しません）
  • 法令上の義務の遵守

3. Google／Apple アカウントでのログイン

ソーシャルログインを利用する場合、当方は Google または Apple から、氏名、メールアドレス、プロフィール画像、アカウント識別子等の基本的なプロフィール情報を取得します。取得した情報はアカウントの作成・認証・本サービス内での表示にのみ利用します。Google API から取得した情報の利用は、Google API サービスのユーザーデータに関するポリシー（Limited Use を含む）に準拠します。

4. 主催者への情報提供

参加者がイベントに参加登録・チケット購入を行った場合、当方は、イベント運営に必要な範囲で、参加者の氏名・ユーザー名・参加状況等を当該イベントの主催者（受付スタッフを含みます）に提供します。提供の目的は、イベントの中止・変更の連絡、返金対応、入場時の確認等です。参加登録・購入の操作をもって、この提供に同意いただいたものとします。主催者が取得した情報の取り扱いは、主催者自身の責任によります。

上記の委託先のうち米国に所在する事業者へは、個人情報が米国で取り扱われることがあります。米国には、日本の個人情報保護法に相当する包括的な連邦法はなく、州ごとの法令（カリフォルニア州消費者プライバシー法等）により保護されています。各国の制度については、個人情報保護委員会による外国の制度の調査結果をご参照ください。

当方は、各委託先の利用規約・データ処理に関する契約等により、委託先が個人情報保護法の趣旨に沿った措置（安全管理措置、目的外利用の禁止等）を継続的に講じていることを確認しています。

7. 保存期間と削除

  • アカウント情報・プロフィール：アカウントの削除まで
  • 利用状況データ：取得から最長 2 年
  • 取引記録（注文・返金・入場の履歴）：法令で定められた期間（最長 7 年）

アカウントはアプリの「設定 → アカウントを削除」からいつでも削除できます。削除すると、プロフィールと投稿画像は削除または匿名化されます。法令上保持が必要な取引記録は、個人を特定できない形で保管します。

8. 利用状況データの送信の停止

アプリの設定から、利用状況データの送信をいつでも停止できます。停止しても本サービスの機能は制限されません。

9. 安全管理措置

当方は、取得した情報の漏えい・滅失・毀損の防止その他の安全管理のために、必要かつ適切な措置を講じます。

  • 通信は暗号化（HTTPS）により保護されます。
  • データベースでは、ご本人・主催者など必要な立場の人だけが必要な情報にアクセスできるよう制御しています。
  • 運営者は個人事業者であり、情報を取り扱うのは運営者本人に限られます。

10. ご本人の権利

ご本人は、当方が保有するご自身の個人情報について、開示・訂正・利用停止・削除、第三者提供の記録の開示を求めることができます。ご希望の場合は下記お問い合わせ先までご連絡ください。ご本人であることを確認したうえで、法令に従い遅滞なく対応します。

11. 未成年者について

未成年の方は、親権者等の法定代理人の同意を得たうえでご利用ください。20 歳未満の方は、20 歳以上を対象とするイベントに参加できません。

当方は、必要に応じて本ポリシーを変更することがあります。重要な変更を行う場合は本ページおよびアプリ内で周知し、変更後のポリシーは掲載時点から効力を生じます。
